# MayAI

**We build AI agents for Italian businesses.**

We help companies automate their workflows with custom AI agents, integrated
with the systems they use every day — Fatture in Cloud, certified email
(PEC), LinkedIn, internal back-office tools.

This profile hosts the **open-source CLIs** we use internally to give those
agents clean, context-efficient access to those APIs.

### Our tools

| CLI | Purpose |
|---|---|
| [`fatture-cli`](https://github.com/mayai-it/fatture-cli) | Fatture in Cloud API wrapper |
| [`pec-cli`](https://github.com/mayai-it/pec-cli) | IMAP/SMTP for Italian certified mail (PEC) |
| `linkedin-cli` *(coming soon)* | LinkedIn internal API |

🌐 [**mayai.it**](https://mayai.it)
